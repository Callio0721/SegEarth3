# 引用登记与论点—原文对照

2026-09-03。此文件区分三种来源：正式论文支持的已有事实、我们日志中的实验事实、本文自己的推导/解释。编号是本地写作索引，不是最终论文引用序号。

## 1. 主论点证据表

| 拟写论点 | 直接来源/位置 | 可以支持什么 |
|---|---|---|
| CLIP 的稠密定位可以通过特征上采样、偏置处理与 attention 重组改善 | C01 §4；C03 §4；C14 §3 | 这些特定方法的操作和结果，而非所有 VLM 都有同一种问题 |
| SAM3 的文本参与共享 concept grounding，并产生不同功能读出 | R01 §3 与架构附录；R02 方法 | 当前骨干与基座结构 |
| 多描述和当前图像视觉证据可用于遥感文本适应 | C02 §3、提示/组件消融 | TMPA 的 CLIP 范式做法；不自动推出 SAM3 两种 256 维表示线性对齐 |
| 约束式 prompt pool 和 semantic-base residual 能组织 SAM3 多提示输出 | R03 方法和模块消融 | ProC 的实际设计 |
| 概念应按分割功能而非仅表征相似度评价 | R04 §2.2–2.3 | 在支持标注上评价/筛选/合并 concept 的流程 |
| 独立类别 prompt 的输出竞争可受证据尺度影响 | R05 §4 | CoCo 的问题与校准，不能冒称我们的三头已证实同样失配 |
| 大范围上下文与高分辨率局部细节有互补性 | R07 §4.1–4.2 | 嵌套 context/detail 分割设计与训练式 scale attention |
| 语言定位可联合使用目标区域与背景上下文 | C15 §3.2–3.3，表征消融 | masked-local/blurred-background-global 与空间指导；不是广域 crop 的同一实现 |
| 对象内部一致性与语义上下文可影响开放词汇分割 | C16 §3、组件消融 | 其谱图蒸馏和 presence-prior 调整 |
| 信息类型可采用不同观察采样 | R06 §3 | Slow/Fast 两条时间采样路径的设计先例；非我们方法的生物学证明 |
| 固定输入下，目标 patch 宽度约 aK/(Lp) | 本文等比例缩放推导 | 采样几何，不是引用他人定理，也不是精度保证 |
| 文本能改变跨视图融合的类别判别边际 | 本文边际定义与线性融合恒等式；本地四路实验 | 一种理论解释，以及当前实现的经验验证 |
| Role/Joint 八基准均提升；匹配交互 6/8 为正、均值 +0.63 | 本地 profiles/interactions CSV | 当前日志对应的配置与结果 |
| 水体/植被收益较强，可移动对象由 −0.02 到 +1.49 | 本地 63 类别对 CSV 与固定分组 | 组统计现象；不替代已测量的区域级因果机制 |
| 方法主表包含多种强模型 | PPT p16、R03 比较表 | 指定的引用数值，不是我们全部重新运行的记录 |
| 独立窗口可产生语义不一致，跨窗口上下文是 OVSS 的具体问题 | R08 §1、§3.2–3.4、Fig.1；R10 §3.2–3.3 | CLIP 类窗口化分割中的实测现象及修正，不直接证明 SAM3 存在相同内部缺陷 |
| 上下文与新文本联合处理已有前例 | R10 §3.3–3.4、Table 2 | Stitch Attention + class-biased prompts；本文差异必须落到角色和 grounding 层级 |
| 两部分应按处理职责连接，而不只并列模块 | R09 §3.2–3.3、Fig.2、Table 3 | align-then-propagate 的方法组织先例；不是我们的精度或严格协同证明 |

## 2. 核心结构/理论引用（不计入 20 篇 CVPR）

### R01 · SAM 3: Segment Anything with Concepts

- Nicolas Carion 等，2025，arXiv:2511.16719。
- [官方原文](https://arxiv.org/abs/2511.16719)；本地 `参考论文/01_基础模型与OVSS主架构/SAM3_2511.16719.pdf`。
- 核对：§3、模型架构附录。视觉 memory 以 prompt tokens 为条件，之后经 decoder/readouts；不要将 attention 方向写反，或将 Presence 简化为对 dense memory 均值池化。

### R02 · SegEarth-OV3: Exploring SAM 3 for Open-Vocabulary Semantic Segmentation in Remote Sensing Images

- Kaiyu Li、Shengqi Zhang、Yujie Wang、Yupeng Deng、Zhi Wang、Deyu Meng、Xiangyong Cao；arXiv:2512.08730，本地 v2。
- [官方原文](https://arxiv.org/abs/2512.08730)；本地 `参考论文/01_基础模型与OVSS主架构/SegEarth-OV3_2512.08730v2.pdf`。
- 用途：基座方法与任务设置。本文实例公式还核对了当前代码的 query admission、inner Presence、outer Presence；公式中保留实现所需的耦合。

### R03 · Prompt-Calibrated SAM 3 for Open-Vocabulary Remote Sensing Semantic Segmentation

- Yanghui Song、Nanqing Liu、Haonan Yin、Yingjie Gao、Chengfu Yang、Qi Ming；2026，ProC-SAM3，arXiv:2606.21863。
- [官方原文](https://arxiv.org/abs/2606.21863)；本地 `参考论文/02_文本概念表示与Prompt适配/ProC-SAM3_2606.21863.pdf`（v2）。
- 核对：方法模块、主比较表。约束概念扩展、类别匹配与 PGRF；主表第三方数值的直接出处。PPT 中 baseline/ours 已按用户指定结果替换，不把整表都称为 ProC 原值。

### R04 · Taming SAM3 in the Wild: A Concept Bank for Open-Vocabulary Segmentation

- Gensheng Pei、Xiruo Jiang、Yazhou Yao、Xiangbo Shu、Fumin Shen、Byeungwoo Jeon；2026，arXiv:2602.06333。
- [官方原文](https://arxiv.org/abs/2602.06333)；本地 `参考论文/06_检索原型记忆与外部知识/ConceptBank_2602.06333.pdf`。
- 核对：§2.1–2.3。以支持标注构造视觉原型和代表支持，按分割功能选择并整合概念。不是只做无标注视觉均值来自动生成概念。

### R05 · CoCo-SAM3: Harnessing Concept Conflict in Open-Vocabulary Semantic Segmentation

- Yanhui Chen、Baoyao Yang、Siqi Liu、Jingchao Wang；2026，arXiv:2604.19648。
- [官方原文](https://arxiv.org/abs/2604.19648)；本地 `参考论文/02_文本概念表示与Prompt适配/CoCo-SAM3_2604.19648.pdf`。
- 核对：§4，语义证据校准、同义聚合及与 SAM3 输出结合。支持跨类别概念竞争的讨论，不支持“我们已实现 latent-space 对齐”。

### R06 · SlowFast Networks for Video Recognition

- Christoph Feichtenhofer、Haoqi Fan、Jitendra Malik、Kaiming He；ICCV 2019。
- [CVF 正式页面](https://openaccess.thecvf.com/content_ICCV_2019/html/Feichtenhofer_SlowFast_Networks_for_Video_Recognition_ICCV_2019_paper.html)；本地 `参考论文/05_场景上下文多视野与跨图证据/SlowFast_ICCV2019.pdf`。
- 核对：§3。低帧率路径处理空间语义，高帧率路径读取运动，以 lateral connections 结合。本文借鉴信息相关观察，不建立生物通路一一对应。

### R07 · HRDA: Context-Aware High-Resolution Domain-Adaptive Semantic Segmentation

- Lukas Hoyer、Dengxin Dai、Luc Van Gool；ECCV 2022。
- [ECVA 正式原文](https://www.ecva.net/papers/eccv_2022/papers_ECCV/papers/136900370.pdf)；本地 `参考论文/05_场景上下文多视野与跨图证据/HRDA_ECCV2022.pdf`。
- 核对：§4.1–4.2。context/detail 嵌套 crop 和训练式尺度注意力。是方法二最直接的分割理论先例，不是免训练 SAM3 或角色文本方法。

### R08 · Looking Beyond the Window: Global-Local Aligned CLIP for Training-free Open-Vocabulary Semantic Segmentation

- ByeongCheol Lee、Hyun Seok Seong、Sangeek Hyun、Gilhan Park、WonJun Moon、Jae-Pil Heo；CVPR 2026 正会，pp. 27686–27696。
- [CVF 正式页面](https://openaccess.thecvf.com/content/CVPR2026/html/Lee_Looking_Beyond_the_Window_Global-Local_Aligned_CLIP_for_Training-free_Open-Vocabulary_CVPR_2026_paper.html)；本地 `参考论文/05_场景上下文多视野与跨图证据/GLA-CLIP_CVPR2026.pdf`。
- 已核对主文 §1–6、Fig.1–3 与 Table 2。VFM 全窗口 key / CLIP value 扩展，proxy anchor 缓解窗口偏置，动态归一化调节尺度；用于同任务上下文动机和区别说明。

### R09 · PEARL: Geometry Aligns Semantics for Training-Free Open-Vocabulary Semantic Segmentation

- Gensheng Pei、Xiruo Jiang、Xinhao Cai、Tao Chen、Yazhou Yao、Byeungwoo Jeon；CVPR 2026 正会，pp. 17927–17937。
- [CVF 正式页面](https://openaccess.thecvf.com/content/CVPR2026/html/Pei_PEARL_Geometry_Aligns_Semantics_for_Training-Free_Open-Vocabulary_Semantic_Segmentation_CVPR_2026_paper.html)；本地 `参考论文/03_视觉语言对齐与稠密表征/PEARL_CVPR2026.pdf`。
- 已核对 §1–5、Fig.2、Table 3–4。末层 query/key Procrustes 对齐，再以文本/图像边缘引导 Laplacian logits 传播；用于两步骤衔接和消融组织，不用它证明 SAM3 同维特征可直接线性对齐。

### R10 · OV-Stitcher: A Global Context-Aware Framework for Training-Free Open Vocabulary Semantic Segmentation

- Seungjae Moon、Seunghyun Oh、Youngmin Ro；CVPR 2026 **Findings**，pp. 7357–7367。
- [CVF Findings 正式页面](https://openaccess.thecvf.com/content/CVPR2026F/html/Moon_OV-Stitcher_A_Global_Context-Aware_Framework_for_Training-Free_Open_Vocabulary_Semantic_CVPRF_2026_paper.html)；本地 `参考论文/05_场景上下文多视野与跨图证据/OV-Stitcher_CVPRF2026.pdf`。

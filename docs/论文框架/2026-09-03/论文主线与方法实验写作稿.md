## 1. 统一主线

**统一的类别概念可以维持共享 grounding，但未必提供每一种计算角色最需要的补充信息；合适的补充语言，还需要能呈现相应证据的视觉观察。**

> **Role-Functional Text specifies what evidence to seek; complementary views determine how that evidence is observed.**

第一部分以角色功能组织补充语言，第二部分在 Local/Global 下重新观察这些语言所指向的证据。两部分都通过完整的冻结 SAM3 grounding，并在已对齐的类别证据上组合，保留预训练的内部协同。

**区别要落在计算职责，而不是“同时用了文本和上下文”。** 后者已有 GLA-CLIP、OV-Stitcher 等邻近探索。[R08, R10] 本文的具体出发点是：同一概念下，存在判断、稠密覆盖与 query 区域组织对补充语言的响应不同；在不拆解共享 grounding 的前提下，按用途读取补充，再检验它在不同观察下的条件价值。

论证顺序：

1. **任务矛盾：** 遥感 OVSS 要把开放概念转为完整像素划分；概念识别、稠密覆盖和区域定位并不承担相同职责。[R01, R02]
2. **我们的观察：** 新文本会影响三种读出，但收益不一致；统一替换不如保留 anchor 后按角色补充。历史探索提出问题，当前消融验证选定实现。
3. **方法一：** 为不同角色提供功能相关的补充信息，保留共同概念锚点与完整 grounding。
4. **进一步的瓶颈：** 语言不能恢复视野外的结构，也不能恢复缩放丢失的细节。视觉观察与语言请求需要一起考虑。
5. **方法二：** 在对齐的 Local/Global 中使用同一角色文本配置，各自形成完整角色证据，再进行跨视图融合。
6. **验证：** 主表回答竞争力，模块表回答作用，匹配四路表回答协同，类别图与分割图回答收益在哪里。

建议贡献表述：

- **Role-functional concept supplementation：** 以共享 anchor 为基础，按计算职责利用补充文本，而非要求同一新增描述统一服务全部输出。
- **Joint role–view evidence composition：** 在完整概念 grounding 下联合组织功能语言与互补观察，利用条件相关的视觉证据。
- **Systematic empirical evidence：** 八个遥感基准、匹配交互与类别分析，展示整体收益及其适用范围。

## 3. Related Work：三个小节

### 3.1 Open-Vocabulary Segmentation from Vision–Language and Segmentation Foundation Models

**写法：先讲计算范式变化，不按年份罗列。**

第一段回答“识别表征如何成为稠密预测”。SegEarth-OV 用 SimFeatUp 和全局偏置处理改善遥感稠密特征；ReAttnCLIP 重组 patch/CLS 注意力作用；ResCLIP 以残差相关性和语义反馈增强空间一致性。[C01, C03, C14] 这些工作说明，免训练方法的核心可以是面向任务重新组织已有表示。

第二段转到“概念驱动的分割”。SAM3 用 concept 条件进行共享 grounding，产生存在性与空间分割输出；SegEarth-OV3 将这些输出组织成遥感语义分割。[R01, R02] 文本因而不只是最后的相似度分类器，而参与后续空间解码的条件化。

**本节落点：** 我们研究共享概念下不同计算职责如何使用补充信息，而非把 SAM3 当作另一种 CLIP 特征提取器。

> Rather than modifying dense similarity extraction, we study how a frozen concept-grounded segmenter can use supplementary evidence according to the roles of its native readouts.

### 3.2 Concept and Prompt Adaptation for Remote-Sensing Segmentation

**写法：比较提示如何形成、由什么评价、在哪里使用。**

| 工作 | 实际流程 | 解决问题 | 本文区别 |
|---|---|---|---|
| TMPA [C02] | 多描述→低熵像素视觉证据→视觉引导的测试时文本适应→稠密预测 | 静态描述不充分或不匹配当前图像 | 本文通过完整 SAM3 grounding 获取角色补充，而非直接移植 CLIP 式线性对齐 |
| ProC-SAM3 [R03] | 约束概念扩展→类别匹配 prompt pool→SAM3 输出→以 semantic 为基础的 Presence-guided residual fusion→类别聚合 | 单提示覆盖不足、多提示输出利用 | 本文按 P/S/I 职责使用补充，再联合视觉观察 |
| ConceptBank [R04] | 支持标注区域原型→代表支持→按分割功能评价 concept→合并概念表示→SAM3 推理 | 通用概念在目标分布中分割功能不佳 | 从“哪个概念表示更好”推进到“哪种信息服务哪种读出” |
| CoCo-SAM3 [R05] | 受约束同义词→中间视觉/文本相似性→同义聚合和语义校准→组合 SAM3 掩膜证据 | 独立概念缺少跨类可比性 | 本文保留基座类别竞争，调整角色补充与观察条件 |

论文中把表压成两段即可：先“从静态名称到功能性概念适配”，再“从概念级适配到角色相关补充”。AVION 可作为视觉原型筛选与提示蒸馏的遥感补充例子，但不挤进主要 OVSS 对比。[C05]

> These methods improve the concept representation or its aggregate response. Our focus is complementary: a useful concept supplement need not benefit existence estimation, dense coverage, and query organization in the same way.

### 3.3 Complementary Context and Multi-Granularity Visual Evidence

**写法：围绕观察与所需信息匹配，不泛称多尺度有效。**

先从同任务说起。GLA-CLIP 针对独立窗口语义不一致，扩展跨窗口 key/value，并以 proxy anchor 缓解局部 query 偏置。[R08] OV-Stitcher 在最后编码层拼接窗口 Q/K/V、形成全局关系，再用类别偏置描述缓解一致区域中的类别误判。[R10，CVPR Findings] 两者说明窗口上下文与文本—区域匹配已是具体研究问题，而非笼统的多尺度直觉。

再交代设计依据：HRDA 组织大范围低分辨率 context 与小范围高分辨率 detail，以学习的尺度注意力组合预测；Hybrid Global–Local 将目标局部与背景上下文用于语言条件定位。[R07, C15] CASS 是对象一致性与语义上下文的补充例子。[C16] SlowFast 最多保留一句观察分工的设计先例，不承担主理论依据。[R06]

**区别段可这样写：** GLA-CLIP/OV-Stitcher 改变跨窗口特征交互，本文不改预训练 attention，而让两种观察分别完成 SAM3 concept grounding；新增语言按 P/S/I 职责使用，最后组合坐标对齐的类别证据。我们检验的是角色补充与观察的条件互补，而不是宣称首次引入上下文或文本＋视觉协作。

**本节落点：** 本文关心互补观察的价值如何随角色文本条件而改变，并在冻结 grounding 后的对齐类别证据上利用它。直接理论依据是 context/detail 权衡，不展开生物学类比。

## 4. Method：四个小节

### 4.1 Frozen Concept Grounding and Overview

第一段定义图像 X、类别 c、anchor 文本 t_A 与冻结模型 Φ。解释 Presence 判断存在，Semantic 产生稠密覆盖，Instance 以 object queries 组织候选区域。[R01]

第二段定义基座，不铺开所有超参数：

\[
(p_c,S_c,\mathcal Q_c)=\Phi(X,t_c),\qquad
F_c=p_c\max\{S_c,\mathcal I(\mathcal Q_c;p_c,a_c)\}.
\tag{1}
\]

\(\mathcal Q=\{M_q,r_q\}\)，M 为 query mask，r 为 object score：

\[
\mathcal I(\mathcal Q;p,a)=\max_{q:ar_q>\eta}M_qr_qp.
\tag{2}
\]

默认 a=p；可选 anchor admission 仅令 a=p_A，不删除幅度中的 p。

第三段用主图串起两部分：

```text
       Class anchor + role-functional supplements
                         │
              ┌──────────┴──────────┐
          Local view           Global view
              │                     │
      Complete frozen SAM3  Complete frozen SAM3
      grounding per prompt  grounding per prompt
              │                     │
      Role supplementation  Role supplementation
      + native P/S/I fusion + native P/S/I fusion
              │                     │
        Restore to common image coordinates
              └──────────┬──────────┘
                 View evidence fusion
                         │
                Baseline decision rule
```

主图用紫/青/橙对应 P/S/I，Local/Global 用浅底框。清楚表示复用同一冻结模型。最后标 **View Evidence Fusion**。

### 4.2 Anchor-Preserving Role-Functional Supplementation

按“功能差异→文本形式→使用方式→anchor 必要性”写四段。

**功能差异。** 新描述共同改变 SAM3 条件化状态，但未必同时改善三种读出。我们对补充结果的用途作区分，而不隔离内部 grounding。

**文本形式。** Presence 候选强调概念/存在形式，Semantic 候选强调外观与覆盖，Instance 候选强调实体或区域组织。现有 bank 中 `tree` 的功能示例有 `tree canopies`、`dense tree canopy`、`separate tree crown`。“区域组织”通过语言条件影响 query 所形成的区域。

**使用方式。** 每条候选完整通过 Φ，只取对应角色作为补充。定义

\[
\mathcal R(a,b)=\operatorname{clip}_{[0,1]}
\{a+\alpha\operatorname{clip}(b-a,-\tau,\tau)\}.
\tag{3}
\]

\[
\tilde p=\mathcal R(p_A,p_P),\quad
\tilde S=\mathcal R(S_A,S_S),\quad
\tilde I=\mathcal R\big(
\mathcal I(\mathcal Q_A;\tilde p,a),
\mathcal I(\mathcal Q_I;\tilde p,a)\big).
\tag{4}
\]

未启用补充的角色保持 anchor。实例两项均用当前 Presence 重建后取残差，保留 P→I 耦合。每个观察单元内仍用 \(F^{role}=\tilde p\max(\tilde S,\tilde I)\)。

**anchor 必要性。** 新描述补充证据，不重新定义类别基础。官方多别名输出通过

\[
G=\operatorname{clip}_{[0,1]}
\{B^{official}+F^{role}-F^{anchor}\}
\tag{5}
\]

保留，零更新回到基座。当前 α=0.5、τ=0.25 等具体设置归入 Implementation Details。直接替换对照见 Table 3。

### 4.3 Complementary Visual Observation and Joint Evidence Composition

**先解释语言为什么仍不够。** 语义条件改变“寻找什么”，不保证当前观察保留所需信息。GLA-CLIP 在 OVSS 中直接展示窗口独立处理的上下文局限；HRDA 给出分割中的 context/detail 互补结构。[R08, R07] 这为构建不同观察提供动机，但本文不据此假定 SAM3 具有完全相同的注意力缺陷。

**给一个直接的几何依据。** 编码输入宽度 K，patch 步长 p，观察在源图中的宽度 L，目标宽度 a。等比例缩放后目标占据的 patch 宽度约为

\[
n(a;L)\approx \frac{aK}{Lp}.
\tag{6}
\]

扩大 L 呈现外围组织关系，却压缩目标采样；缩小 L 保留细节，却减少上下文。两种观察由此提供不同的模型可用证据。这是自己的几何推导。

**落到实现。** Local/Global 各自运行相同的 anchor/role 补充流程，按当前整图/滑窗路径恢复坐标并聚合，得到 \(\bar G_L,\bar G_G\)：

\[
Z_c(x)=\Psi\big(\bar G_{L,c}(x),\bar G_{G,c}(x)\big),
\qquad\hat Y=\mathcal D_{baseline}(Z).
\tag{7}
\]

Ψ 是视图证据融合环节；基座类别决策与背景阈值保留。主图只显示融合环节，实际配置放复现表。两个视图都提供完整 grounding，每个角色在两种观察下都有对应的输出。

可直接发展的英文段：

> Functional language specifies the evidence to seek, but its utility also depends on the observation under which grounding is performed. At a fixed encoder resolution, a broader field exposes spatial organization while reducing the sampling density of local structures. Conversely, a tighter view preserves detail but omits surrounding context. Motivated by contextual limitations of windowed OVSS [R08] and context–detail representations in segmentation [R07], we ground the same role-functional concept configuration under aligned local and global observations. Their class evidence is composed after complete native grounding, retaining the model’s learned coupling between recognition and spatial prediction.

### 4.4 Conditional Complementarity

正文用一小段解释两部分为何相接：相同补充文本在 Local/Global 中未必产生相同的类别判别变化，因而某个视图组合的作用取决于它所承载的角色文本条件。完整 grounding 保留这类图文相互作用，后端融合利用其互补的类别证据，而不要求在模型内部新增跨视图连接。

这个解释对应一个明确实验：固定 Joint 所选文本与 View 配置，比较 Baseline、Role、View、Joint 四路，区分模块主效应与额外交互。当前匹配结果为 6/8 正交互、macro +0.63；各行数值及 Γ 定义放 §5.4，不在 Method 重复结果表。完整边际推导留在文末“补充材料候选”，不是新增算法模块。

## 补充材料候选：Role × View 的判别边际分析

下面保留完整推导供补充材料或组内讨论。正文只保留 §4.4 的机制摘要；公式编号在正式排版时统一重排。

定义视图 v、文本 T 下真实类 y 对竞争类 j 的分数边际：

\[
m_v(T;y,j)=G_{v,y}(T)-G_{v,j}(T).
\tag{8}
\]

以线性融合为可分析实例：

\[
m_\lambda(T;y,j)=(1-\lambda)m_L(T;y,j)+\lambda m_G(T;y,j).
\tag{9}
\]

补充文本可改变各视图中目标类与相邻概念的相对边际，因此能纠正某像素的融合区间依赖 T。同一个 View 组合对 anchor 无益，也可能在角色文本改变边际后得到正确决策。相反，若两种观察强化相同错误，联合使用不自动有效。

这个联系还可以写得更具体。以 Local 为分析参考，令 \(\delta m_v=m_v(T_R)-m_v(T_A)\)，则视图融合带来的边际变化 \(d_V(T)=\lambda[m_G(T)-m_L(T)]\) 满足

\[
d_V(T_R)-d_V(T_A)=\lambda(\delta m_G-\delta m_L).
\tag{9a}
\]

这说明：**当相同补充语言在两个观察下引起不同的判别变化时，View 的作用就不是与 Role 无关的固定增量。** 若 Global 的新增证据更能拉开真实类与竞争类，融合可能弥补 Local 的负边际；若两视图响应相同，则没有这种额外边际交互。这给出了联合组织的具体理由，而不只是“多模态可能互补”。

例如当 \(m_L<0<m_G\) 时，二类别竞争被纠正的线性融合条件是 \(\lambda>-m_L/(m_G-m_L)\)。文本改变两个边际，也就改变可纠正的区间。多类别情况下需同时满足真实类相对各竞争类的条件；背景阈值仍按基座处理。该推导仅解释一个融合实例，实际 Ψ 的不同实现仍由消融检验。

联合收益因此可以来自“文本改变互补视觉证据的判别方向”，不要求内部存在跨视图 attention。实验使用固定文本与融合配置的四路结果：

\[
\Gamma=m_{11}-m_{10}-m_{01}+m_{00},
\tag{10}
\]

m 为数据集 mIoU，对应 Joint/Role/View/Baseline。当前 **6/8 正、平均 +0.63**。公式 (9) 解释协同的决策机制，匹配实验验证当前实现的条件互补性。

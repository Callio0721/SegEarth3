# Potsdam / Vaihingen 单图 Role–View 实验

分析日期：2026-09-04。结果源：[完整汇总](../../logs/joint_role_view_single_image_v1_full_bc5a250/summary/joint_role_view.md)。本轮只分析与记录，不改代码、PPT或历史论文表格。

## 1. 先看实际结果

两个数据集分别覆盖 **2016 / 398** 张图；汇总无缺失数据集、无重复记录。每个数据集有7组Role候选（含anchor）×15种视图配置（Local、Global及13种混合）加1个official对照，共106个变体。Global来源全部为 `full_image`；identity与prompt-parity误差均为0。回传包含汇总、配置和运行指标，未包含逐图rank JSONL，因此完整性依据回传汇总而非再次逐条扫描原始记录。

本次：当前512×512图像为Global，四个256×256裁块分别完成完整grounding，再恢复坐标组成Local；不读取相邻图像。

| 设置 / mIoU | Potsdam | Vaihingen |
|---|---:|---:|
| Baseline，即Anchor–Global | 57.87 | 60.86 |
| Anchor–Local | 48.67 | 49.99 |
| Role–Global | **58.59** | **62.33** |
| 相同Role–Local | 49.53 | 50.97 |
| 最佳View-only（允许选端点） | 57.87，Global | 60.86，Global |
| 最佳实际双视图混合（不含端点） | 58.43，linear-g0.75 | 61.65，logit-g0.75 |
| 全部候选中的Joint best | **58.59，Global** | **62.33，Global** |
| Joint best − Baseline | **+0.73** | **+1.47** |
| Joint best − 最佳Role-only | **0.00** | **0.00** |

最佳Role配置：Potsdam为 `P1+S2+I0 / anchor_admission`；Vaihingen为 `P0+S3+I1 / native`。二者也是各自最佳实际混合的文本配置。g表示Global权重。

**结论：第一方法保持有效；本次256/512视觉方案未在任一数据集的最佳Role-only之上增加mIoU。** “Joint best”包含端点，故这里不代表双视图成功融合。

## 2. 和此前邻域上下文结果的关系

| 协议 | Local | Global |
|---|---|---|
| 历史邻域上下文 | 当前512×512图像 | 利用相邻图像重建的1024×1024范围 |
| 本次单图 | 当前图内四个256×256裁块 | 当前512×512图像 |

历史Local与本次Global是同一个512端点。对相同文本，实际汇总数值完全一致（包括Potsdam `current`、Vaihingen `current` 和 `semantic_i2`）；不是Role-Text链路复现漂移。注册表中的更早Role参考值存在0.001/0.018的差异，不影响上述同期端点一致性。

| 比较 | Potsdam | Vaihingen |
|---|---:|---:|
| 历史邻域Joint best | 63.18 | 66.38 |
| 原最佳文本/准入/算子，仅换本次视图 | 58.43 | 58.86 |
| 本次重新比较现有候选后的best | 58.59 | 62.33 |
| 本次best − 历史邻域best | **−4.59** | **−4.05** |

历史Vaihingen最佳为 `P0+S3+I2 / native / max`，本次该固定配置为58.86。汇总中的 `sequential=59.09` 则是旧Role-only最佳 `P0+S3+I1 / max`，不要把两者混为一条配置。

这支持：此前较大增益需要其较广上下文观察条件，不能直接改称“只用当前512图像内部裁剪也得到相同增益”。但本实验同时改变视野、目标相对尺度与裁块边界，不能单独确定损失全部来自哪一因素，更不能归因于“图像文件数量”。

## 3. 不是一个算子没选好

固定各自最佳Role：

| 算子 | Potsdam | Vaihingen |
|---|---:|---:|
| Global | **58.59** | **62.33** |
| 75% Global线性融合 | 58.43 | 61.50 |
| 75% Global logit融合 | 58.20 | 61.65 |
| 50% Global线性融合 | 56.75 | 59.32 |
| 25% Global线性融合 | 53.81 | 55.89 |
| max | 56.05 | 59.09 |
| Local | 49.53 | 50.97 |

两个当前最佳Role各自的13种实际混合全部低于Global。线性融合中减少Global占比，结果持续下降；这比一个孤立失败参数更能说明Local端点不适合直接补入当前最优预测。

仍有局部正证据：Potsdam次优文本 `P1+S3+I0` 的Global为58.12，linear-g0.75为58.34（+0.21），其13种混合中2种优于自身Global；但仍低于最佳Role-only 58.59。Vaihingen全部7组候选的91个实际混合均未超过各自Global。因此不能写“所有文本下Local完全无用”，也不能据这一个次优正例宣称第二方法已改善总体最佳。

## 4. 类别上改好了什么、损害了什么

### 4.1 第一方法依然产生真实类别收益

| 类别 | Potsdam Baseline | Potsdam Role | ΔIoU | Vaihingen Baseline | Vaihingen Role | ΔIoU |
|---|---:|---:|---:|---:|---:|---:|
| road | 73.70 | 73.80 | +0.10 | 75.96 | 78.33 | +2.37 |
| building | 84.76 | 84.60 | −0.16 | 87.20 | 87.80 | +0.59 |
| grass | 57.26 | 56.61 | −0.65 | 52.50 | 53.72 | +1.22 |
| tree | 37.77 | 43.02 | **+5.25** | 74.41 | 73.92 | −0.49 |
| car | 76.94 | 76.20 | −0.74 | 68.20 | 70.21 | +2.01 |
| clutter | 16.77 | 17.33 | +0.56 | 6.89 | 10.03 | **+3.14** |

Potsdam主要恢复tree，Vaihingen有5/6类别提高。Role在Local本身也相对Local-anchor提高：Potsdam +0.86、Vaihingen +0.98。视觉端点很差，不等于Role补充的作用路径被完全破坏。

### 4.2 混合会侵蚀哪些已有收益

Potsdam最佳实际混合linear-g0.75相对Role–Global：tree −1.95、car −1.10、building −0.37；road +0.86、grass +0.31、clutter +1.26，最终mIoU −0.17。与此同时aAcc从77.08到77.48，总正确像素净增加约1.96M；说明总像素数增益与等权类别mIoU不是同一评价。

Vaihingen原固定算子max相对Role–Global：car **−13.15**、building −2.67、road −1.68、grass −1.38、tree −0.99；仅clutter +0.41，最终mIoU −3.24。max不是本次最佳混合，这组类别数据用于说明一个有记录的损害机制，不能替代logit-g0.75的逐类结论。

当前class CSV只导出汇总所选的7种profile，不含所有106个变体的逐类矩阵，也不含独立P/S/I质量轨迹。不能从这些聚合量判断错误究竟首先产生于哪个head。

## 5. Local有互补像素，但尚不可用作最优方法收益

固定当前Role，Local/Global之间：

| 诊断 | Potsdam | Vaihingen |
|---|---:|---:|
| Global mIoU | 58.59 | 62.33 |
| Local mIoU | 49.53 | 50.97 |
| GT Oracle mIoU | 64.15 | 65.06 |
| Oracle − Global | +5.55 | +2.73 |
| Local正确、Global错误像素 | 25.59M | 2.85M |
| Global正确、Local错误像素 | 57.73M | 11.44M |

Global独有正确像素分别约为Local的2.26倍、4.01倍。Local确实提供部分正确证据，但同时丢失更多原本正确的判断。当前聚合方式不能稳定区分二者。该诊断不支持重新启动无独立证据的像素路由/自置信校准。

交互也要区分净收益：Potsdam当前Role配linear-g0.75的Γ为+0.07，Vaihingen配logit-g0.75为+0.30；但对应View主效应分别为−0.23、−0.98，尚不足以变成额外正收益。最终选Global时，View主效应与Γ都为0。

统一limitation：**互补观察需提供足够的有效场景结构与尺度信息；已有预裁图再切得更小，会让上下文损失与目标尺度变化抵消局部细节收益。** 此处前半句由结果支持，后半句是符合端点趋势的解释，尚未由单变量实验拆开验证。

因此保留Role-Functional Text主线；对这两个数据集，当前单图方法允许退回Global。第二方法的叙事应是“利用有价值的互补观察”，不是“任意多切一张图都会提高”，也不再以这两项作为单图条件下的强协同案例。

## 7. 推荐动作

先按实际结果归档：本次单图最佳58.59/62.33，邻域上下文63.18/66.38单独保留。不要继续在256/512上扩大算子或文本搜索。

若用户仍希望改善单图第二方法，唯一建议的下一项是**更大、重叠的Local观察**（例如384/512），固定当前Role文本与少数现有算子，检验减少上下文截断是否能改善端点并保留互补性。这是一个不同观察实现的最小验证建议，尚未批准实现或运行；不据本轮失败否定所有单图多尺度方案。

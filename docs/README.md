## 记录如何分工

- `state.md`：当前方法、准确结果、状态和下一步，只保留关键历史结论。
- `研究记录/`：完成的试错/实现事件，不复制一份不断变化的“最新主表”。
- `论文框架/`：唯一持续修订的写作框架；不为每轮聊天复制一个“最终版”。
- `logs/*/summary/`：实验数值的原始汇总依据，不整理、改写或删除原始日志。
- `参考论文/索引.md`：回答“原文在哪里、做了什么”；写作目录的引用对照回答“哪句话由它支持”。
- `output/pdf/category_evidence_20260903/`：当前类别组主图；其数据和复画入口在论文框架目录。
- `tmp/`：只放可再生的抽取文本、渲染预览，完成后清理。

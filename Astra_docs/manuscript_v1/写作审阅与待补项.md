## 1. 本版已经交付什么

本版是三个章节的实际初稿，不是写作提纲：

- Related Work：三条研究脉络，解释代表工作如何处理密集预测、提示适配和互补观察，并落到本文差异。
- Method：四个小节，给出输入输出、原生 P/S/I 耦合、角色补充、官方结果补偿、视图坐标恢复和最终组合。
- Experiments：五张有真实数据的正文表，分别回答竞争力、同文本不同用途、组件交互、类别收益和自然域边界。
- 附表：已选配置、独立最优组件、Residual/Direct、目标图块内视图控制、完整 18 组同文本对照，以及明确留空的待补比较。
- 文献：50 篇 CVPR 主会写法语料及逐篇记录；正文实际引用的 23 篇另有编号、官方链接与 BibTeX。**写法学习库不等于正文需要塞入 50 个引用。**

英文主文件约 4,200 个按空格计数的词项，包括表格、公式片段、标题与占位图注，不是最终排版后的正文字数。该版先保证论证完整；正式双栏版中可把部分公式合并、类别组表转为柱状图，避免挤压主图。

## 3. 我对本稿的实际判断

### 3.1. 现在的中心论点是成立且连贯的

主线不是“给三个头分别加新文本，再加多尺度”，而是：

> 同一概念定位系统具有不同输出职责；补充信息的用途需要与职责匹配，而补充信息的价值还取决于它所面对的视觉观察。我们保留共享定位，以角色用途组织语言证据，并在互补观察下联合组合。

这条主线有三层对应证据：

1. 同一 Semantic 候选用于一个角色与共享给所有角色，会得到不同的最终质量；13/18 有利于 Semantic 专用，但存在相反案例。
2. 最终框架在八个遥感数据集上均超过配对 baseline，平均从 53.56 到 57.49；类别上不是只靠一个大背景类。
3. 固定配置的交互平均 +0.63，六个数据集为正；LoveDA/UAVid 中 View 从对 anchor 略有害转为对 Role 有益，说明不是两份独立固定收益的简单累加。

因此可以写“角色敏感、观察依赖的证据利用”，还不能写“已经证明每个 head 都需要一种唯一最优语言类型”或“每个角色已经有专属视觉路径”。

### 3.2. 理论目前应该写到哪里

理论的扎实程度来自三件真实的事，而不是增加术语：

- **计算耦合：** Presence 是标量，却可通过查询准入影响空间实例证据；不同角色增益不必可加，这是实际计算可解释的。
- **采样与上下文取舍：** 相同模型输入尺寸下，扩大源视野会减少对象的 token 占比，同时增加可访问背景关系。式中的 (dR/(Ls)) 是尺寸换算，不是新增定理，也不是性能保证。
- **条件互补：** 语言决定模型对何种概念证据作出响应，观察决定有哪些可用视觉证据。匹配交互能检验二者在性能上是否互补；它不能单独定位到某个 attention 层或每个 query 的因果变化。

这种理论解释比“更懂遥感”具体，也与当前 frozen、完整 grounding、输出层组合的实现一致。没有把 CLIP 式视觉—文本线性对齐假设套在 SAM 3 的同维状态上。

### 3.3. 本版不宣称已经填平的两个缺口

**角色用途与普通多提示的区分还可更直接。** 当前同文本对照已经有信息，但最终角色组合来自较丰富的候选库。最有用的补充是固定同一候选信息，比较角色敏感使用和普通完整预测集成；已有 18 组 Semantic 候选对照不能覆盖这一完整问题。因此正文表述为有证据支持的设计，而不是宣称排除了所有多提示解释。

**协同的空间解释需要真实预测图。** 正交互和类别分组能支持宏观结论，但不能据此编写“图中补上了某条道路连接”。本稿为定性图留了精确的面板需求，没有生成假分割图。只有对应 variant 的实际输出才能承担这部分论证。

## 4. 八页主文的落版建议

以下是撰稿配比，不是 CVPR 的固定章节配额。参考文献按投稿模板和届时官方规则排版。

| 内容 | 建议篇幅 | 功能与展示 |
|---|---:|---|
| Abstract + Introduction | 约 1.35 页 | 一条问题主线，代表性动机图或小示例，凝练贡献；本轮未写 |
| Related Work | 约 0.70 页 | 三组问题—解法，最接近 SAM 3 / 文本与上下文工作主动比较 |
| Method | 约 2.45 页 | 含约半页横跨双栏的主图；主要解释式（2）、角色更新与视图对齐组合 |
| Experiments | 约 3.20 页 | 主表、匹配消融、用途控制、类别组图、定性图及自然域简表 |
| Conclusion | 约 0.15 页 | 归纳已验证贡献及边界；本轮未写 |
| 版式余量 | 约 0.15 页 | 图注与浮动表格空间 |

主图不重复 50 篇论文的复杂视觉元素。最适合本稿的是三段：**complete concept grounding → role-functional supplementation → aligned view composition**，在 grounding 内保留小型 P/S/I 输出示意；Local/Context 共用同一角色配置。主图中不列所有算子与候选编号，附表 A1 承担这些信息。

正文的类别表可替换为成组增益柱状图：每组并排画 Role ΔIoU 和 Joint ΔIoU，明确权重为“数据集—类别对”。交互表优先保留真实数值，因为它比复杂热图更直接回答本文的第二个核心问题。

## 5. 下一版只需优先补什么

1. **一个同信息量的用途控制。** 固定最终提示候选池与观察，在角色敏感使用、共享/角色无关使用、完整预测集成之间做紧凑比较；固定角色置换可以作为同表的辅助列。附表 D 已留空，不用重开一整簇方法。
2. **一组配对的真实定性图。** 对同一图像导出 Baseline、匹配 Role、匹配 View、Joint，优先 OEM、UAVid/LoveDA、Vaihingen，并包含一个有限收益案例。若现有输出身份与坐标吻合就复用。
3. **整理最终提交所需的描述与数据来源。** 已有选中配置和文本不重新生成；补充材料给原样提示表、评测协议和数值出处。主表 baseline 的固定参考与配对日志的差异需给出明确来源或最终采用决定。

不是所有空表都必须新增完整八数据集实验才能继续写论文。先完成最能区分中心解释的匹配对照，再决定哪些补充进入主文或附录。本轮不新增模型实验，不重新打开已停止的结构方向。

## 6. 集中列出的真实性与准确性检查

### 数值与评测口径

- 主结果保持用户选定的 **57.49**，没有用 Direct 或后期诊断的个别更高值拼出新主表。
- 用户指定的外部比较 baseline 平均 **53.50** 与同次配对日志 **53.563854… → 53.56** 不是同一个数的正常舍入结果。当前主表保留既定参考；正文所有差值使用配对记录，得到 **+3.92**，不把 57.49−53.50 混成消融增益。正式主表定稿需进一步确认固定 baseline 每格来源。
- 独立最佳 Role-only 平均 **55.82**；固定最终 Joint 角色配置后的 Role 平均 **55.67**。交互必须使用后者，所以匹配 Γ 是 **+0.63**；Joint 对独立最佳 Role 的增益另报 **+1.67**。
- iSAID 已使用真实 Joint **29.13**，不再使用 PPT 曾临时约定的 28.30。
- Cityscapes 精确值为 72.195189…，两位小数应为 **72.20**；本版已修正，不按先前截断的 72.19 沿用。
- 类别组平均不是八数据集宏平均；429.16M 等像素计数不是独立地理样本数量。没有把背景均值较大的现象替代前景结论。

### 协议与方法

- 全部 SAM 3 权重冻结，与“没有利用过评测标注选择配置”是不同声明。本稿按实际情况一次性写明 evaluation-selected profiles；固定后推理不读 GT。不重新要求用户采用 train/support 选择。
- Potsdam/Vaihingen 访问同原始场景的邻接 RGB，构造更大视野；在设置与相关附表中说明。没有改称仅依靠当前 512 图块，也没有误写成直接输入整幅原始正射影像。
- 零角色更新的 identity 指观察内回到该观察的官方 baseline；添加第二观察后仍可能产生 View-only 改变，不声称整个多视图输出无条件等于单视图 baseline。
- Query 是模型解码的区域槽及其 mask/score，不是类别文本 embedding。Instance 的区域组织语言不是显式连通性约束。
- 保留完整 grounding；没有三头内部隔离、逐头专属视图或特征空间融合。P 对 I 的耦合、别名基准补偿与分数坐标对齐均在公式中体现。
- Direct 对照同时移除了 bounded anchor 更新与官方分数补偿，因此不能把巨大差值全部归因于 clip 或某一个 α。

### 文献与比较

- 正文 23 条引用对应 [references.md](references.md) 与 [references.bib](references.bib)。CVPR 主会、Findings、arXiv、ECCV 和 ICML 分别标识；已核验但未正式刊出的 arXiv 版本不擅自写成 CVPR 接收。
- ProC-SAM3 是语义基本盘上的门控非负实例残差，不写成我们一样的 P/S/I 三类文本分工。ConceptBank 使用带标注 support 评价候选，不写成完全无标注概念选择。TMPA 的 CLIP 测试时更新与我们的冻结输出补充区别已保留。
- GLA-CLIP、OV-Stitcher 已有全局—局部与文本相关先例，因此不声称“首次使用文本加上下文”。本文差异具体落在 SAM 3 的角色化输出用途与其观察依赖性。
- 其他模型数值由 ProC-SAM3 的比较表转录，正文明确来源；没有冒称本项目已逐个重跑。正式投稿时再补其原始论文引用与逐模型协议核对，尤其不要把当前“最高展示平均”直接写成无条件 SOTA。
- 不把“50 篇写法学习”冒充一次无遗漏的新颖性检索。该语料用于学习论证与版面，最接近工作仍需要按实际机制比较。

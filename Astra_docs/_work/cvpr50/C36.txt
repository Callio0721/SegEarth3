Abstract
Contrastive Language-Image Pre-training (CLIP) offers a
new paradigm for Weakly Supervised Semantic Segmenta-
tion (WSSS) by generating Class Activation Maps (CAMs)
from text-image alignment. Existing methods primarily rely
on hand-crafted templates or general attribute descriptions
generated by a large language model to construct text pro-
totypes for querying visual features. However, these strate-
gies faces two major limitations: the inherent modality gap
in CLIP prevents text prototypes achieving tight alignment
with visual features; and their static text prototypes can-
not adaptively respond to target instances that exhibit di-
verse visual attributes. To address these challenges, our
key insight is to directly construct instance-specific visual
description prototype as query, thereby bypassing the sub-
optimal static text description optimization. To this end,
we propose the Visual Description Assembly (VDA) frame-
work. It employs a probabilistic model to map complex
CLIP visual features into a structured latent space. This
latent space allows us to explicitly disentangle and aggre-
gate varied visual attributes, and then dynamically assem-
ble them into instance-specific visual prototypes. Further-
more, to enhance the robustness of this prototype, we adap-
tively incorporate the semantically stable text prototype into
it as the final query for generating superior CAMs. Ex-
perimental results show our method outperforms existing
baselines, achieving state-of-the-art performance on WSSS
benchmarks. Code is available at here.

Recently, Contrastive Language Image Pre-training
(CLIP) [25] has revolutionized many advanced tasks [13,
21, 30, 31]. In WSSS, CLIP leverages the vast pre-trained
knowledge to construct the text-image relationship and
achieve better CAMs beyond traditional classification net-
works [17, 18, 37, 42, 48]. These CLIP-based WSSS meth-
ods use CLIP text feature as query to activate CLIP visual
features. For instance, CLIP-ES [17] and WeCLIP [48]
typically rely on simplistic, hand-crafted templates (e.g., ‘a
clean origami of [CLASS]’). But such templates only con-

necessary for fine-grained localization. Recognizing this
limitation, subsequent work, like ExCEL [42], attempts to

on improving the textual description, while failing to ad-
dress a more fundamental flaw:the inherent modality gap
in CLIP, where image and text embeddings reside in differ-

Thismodality gapintroduces two critical issues. On
the one hand, as visualized in Fig. 1(I), the text prototype
(even highly descriptive one) often lie outside the actual vi-
sual feature clusters. This is because CLIP text embeddings
were optimized for general semantic representation to facil-
itate global alignment, rather than fine-grained visual under-
standing, such as segmentation. This misalignment funda-
mentally hinders the ability of query to respond accurately
to fine-grained visual details, leading to incomplete CAMs.
On the other hand, these text refinement approaches are in-
herently static; a single, fixed general prototype, regardless
of its richness, cannot adapt to the vast diversity of visual at-
tributes across different images. For instance, as illustrated
by the red dashed circles in Fig. 1(I), visual features corre-
sponding to a similar class attribute (e.g., ‘head of train’)
but from different images form distinct, scattered clusters
in the CLIP space. In contrast, the static text prototype is a
single fixed position that lies between these clusters. Conse-
quently, this varying proximity to the visual clusters results
in inconsistent activation strengths, as the static query can-
not dynamically align well with all of them.
To solve these issues, we propose a novel framework
called Visual Description Assembly (VDA) which directly
construct the query prototype containing target-specific at-
tribute descriptions from the visual feature clusters, thus
bridging the modality gap. The primary challenge for
achieving VDA is that the attribute-related visual features
in the raw CLIP space are scattered and entangled. As illus-
trated in Fig. 1(I), although the visual features correspond-
ing to the ‘head of train’ attribute appear in clusters (a), (b),
and (c), they are scattered across the space rather than form-
ing a single compact group. Moreover, within each cluster,
the features of target attribute are inextricably mixed with
other attributes, making it difficult to separate them. We
address these challenges by mapping the complex distribu-
tion of CLIP visual features onto a structured latent space,
i.e., Gaussian mixture model (GMM). This structured space
allows class-varied visual attributes to be explicitly disen-
tangled and aggregated. For any given target object, we
can compute its dynamic response strengths to these at-
tribute components, enabling us to dynamically assemble an
object-specific visual prototype. Besides, to mitigate poten-
tial errors in the visual prototype, we adaptively fuse it with
the text prototype, which serves as a semantic anchor to ob-
tain the final robust query prototype for superior CAMs.
Collectively, the main contributions of this paper can be
summarized as follows:
•We explore the suboptimal CAMs caused by the modality
gap and static text in previous CLIP-based WSSS, and
propose a framework that directly assembles description
from the visual space to replace text description.
•We leverage probabilistic model to map CLIP visual fea-
tures into structured latent space, enabling explicit disen-
tanglement and assembly of visual attributes into a dy-
namic visual prototype. We also adaptively fuse this pro-
totype with the text template to generate robust query.
•Our method achieves new state-of-the-art WSSS perfor-
mance with only image-level labels on both Pascal VOC
2012 and MS COCO2014 dataset.
2. Related Works
2.1. Weakly Supervised Semantic Segmentation
Weakly supervised semantic segmentation based on image
level labels typically uses classification networks to gen-
erate CAM to provide dense supervision [19, 41, 43, 47].
However, classifier CAM can only cover a limited discrimi-
native area. So the focus of WSSS is on how to extend CAM
to the complete target object and many works have made
innovative attempts. SIPE [2] utilizes image-specific class
prototypes to construct the semantic relationships between
image pixels to refine CAMs. MCTformer [38] learns the
attention between multi-class tokens and image patch To-
kens to generate the CAM. BRNF [24] models pixel fea-
tures via normalizing flows [9, 45] to extract fine-grained
semantic information to assist the classifier CAM genera-
tion. PSDPM [52] mines secondary discriminative pixels
via foreground pixel estimation to generate a more com-
plete CAM. Despite the progress made by these methods,
constrained by the limited semantic information that image-
level supervision provides to classification networks, the
generated CAM still fails to accurately cover the target.
2.2. Vision-Language Pre-training
Contrastive Language Image Pre-training (CLIP) [25] is
a model trained on large-scale image-text pairs, which
shows strong generalization ability across various down-
stream tasks [7, 22, 23, 30, 32, 34, 40, 50]. MaskCLIP [53]
generates pseudo-labels based on the alignment between
CLIP text and image modalities to train segmentation net-
work. CLIP-RC [49] transfers the image-level knowledge
of CLIP to dense segmentation by introducing region-level
cues. Some recent studies introduce CLIP into WSSS,
achieving encouraging progress. CLIMS [37] incorporates
additional natural language supervision from CLIP to acti-
vate more complete objects and suppress open background
noise. CLIP-ES [17] extracts GradCAM from the zero-
shot classification process of CLIP. WeCLIP [48] further ex-
plores using the frozen CLIP visual encoder as a backbone

Framework Overview.The overall framework of our VDA
is shown in Fig. 2. It assembles attributes from the vi-

ing text prototype. To separate visual attributes from vi-
sual space, we first propose Visual Attribute Modeling and
Decoupling (V AMD) which uses invertible neural network
(INN) [1] to model the CLIP visual features to structured
GMM where we can explicitly decoupling attributes within
class. Then, to assemble these attributes into a visual pro-
totype, we propose Visual Description Assembly and Fu-
sion (VDAF). It dynamically assembles attributes based on
the target response to class attribute components in GMM,
and adaptively fuses the text prototype to generate final ro-
bust query prototype. This query prototype, containing rich,
target-specific visual attribute descriptions, is used to acti-
vate the visual features for superior CAMs. Besides, to en-
hances the semantic consistency of decoder features, we de-
sign Decoder Semantic Enhancement (DSE) module which
uses the class prototypes from GMM as semantic anchors
to conduct contrastive learning in decoder.

4. Experiments and Results
4.1. Experimental Settings
Datasets and Metrics.We evaluate our method on two
standard WSSS datasets: PASCAL VOC 2012 [6] and MS
COCO 2014 [16]. PASCAL VOC contains 21 classes
and is extended with SBD dataset [8] following previous
method [35, 46, 55]. The train, val, and test set consist of
10582, 1449, and 1456 images, respectively. MS COCO
contains 81 classes, with train and val sets comprising
82,081 and 40,137 images, respectively. Mean Intersection-
Over-Union (mIoU) is used as the main evaluation metric.
Implementation Details.We adopt ViT-B as the archi-
tecture for the frozen CLIP image encoder and enhance its
fine-grained knowledge as in [42]. The architecture of seg-
mentation decoder and the adapter also follow [42]. The
architecture of INN mainly follow the RealNVP [4]. For
hyperparameters, we set the reliable instance prototype fil-
tering thresholdηto 0.95, the number of visual attributes to
8 for each class, and the loss termλin Eq. (16) as 0.2. For
training on PASCAL VOC, batch size is 4, while for MS
COCO, it is set to 8. The batch size of reliable prototype
setBis 16. The adapter and decoder are trained using the
AdamW optimizer with learning rate 1e-4 and weight decay
1e-2. The INN is trained separately using the Adam opti-
mizer with learning rate 2e-4 and weight decay 1e-4. The
total training iteration is set as 30,000 for VOC and 100,000
for COCO. All experiments are conducted on a single RTX

5. Conclusion
In this paper, we tackled the inherent modality gap and
static prototype limitations in CLIP-based WSSS. We intro-
duced Visual Description Assembly (VDA), a novel frame-
work that bypasses flawed text optimization by constructing
dynamic, instance-specific prototypes directly from the vi-
sual space. We use learnable probabilistic modeling process
to map entangled and scattered visual features to a struc-
tured latent space, explicitly disentangling and aggregating
varied visual attributes. These attributes are then dynam-
ically assembled based on the object response and adap-
tively fused with the stable text anchor, creating a robust
query prototype to generate superior CAMs. Our approach
achieves new SOTA performance on both PASCAL VOC
2012 and MS COCO 2014 benchmarks.

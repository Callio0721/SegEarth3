# 论点—证据—边界

| 论文论点 | 直接证据 | 可以写到什么程度 | 不能写什么 |
|---|---|---|---|
| P/S/I 对补充信息的需求不同 | role text screen；同文本不同作用范围结果差异；8数据集 role profiles | supplementary evidence should be organized by readout responsibility | 三头完全独立；每头永远需要新文本 |
| Anchor 需要保留 | replacement vs bounded residual；Residual vs Direct closure | anchor-preserving composition is a robust default | clipping 单独贡献了全部增益 |
| 完整 grounding 不能硬拆 | anchor-clamped replay 全面下降 | retain pretrained coupled grounding and specialize evidence usage | SAM3 内部 attention 不会受益于任何未来改动 |
| 视觉范围提供互补证据 | Shared Canvas、View-only、Local/Global oracle、Joint results | local detail and broader context expose complementary evidence | 任意多尺度融合都有效；每个 head 固定偏好某一 view |
| Role 与 View 存在条件互补 | matched 2×2 Γ：6/8 positive，macro +0.626；LoveDA/UAVid 反转案例 | role-conditioned evidence changes when an observation becomes useful | 所有数据集 1+1>2；interaction 就等于因果表示交互 |
| 最终方法真实纠正了大量错误像素 | wrong→correct / correct→wrong 统计；class IoU | gains reflect real corrections, especially weak/moderate classes | 每个类别都提升；pixel net 与 mIoU 必然同步 |
| 方法具有一定跨域性 | Cityscapes +4.292；VOC20 +0.218 | role-functional evidence is not limited to remote-sensing class wording | 同一遥感 profile 零修改迁移；View 在自然域同样稳定有效 |
| 方法优于当前严格可比公开结果 | internal 57.487 vs ProC 56.1 | numerically exceeds the strongest verified published eight-dataset result | 已经建立公开 SOTA 或经过独立复现 |

## 建议的 limitation

1. Role candidates 与 Joint profiles 当前由验证集实验选择，不是自动生成的通用 predictor。
2. Local/Global operator 不统一，说明证据尺度与数据分布仍有关。
3. Potsdam/Vaihingen 主结果扩大了 baseline 可访问的 RGB 上下文；必须在实验协议中说明。
4. iSAID/UDD5 的负 interaction 说明两类补充有时重叠；Cityscapes 说明 View 部分并非普遍成立。
5. 当前不修改 SAM3 内部 representation；论文贡献是 training-free evidence organization，而不是新的可训练 architecture。

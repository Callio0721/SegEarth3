# 相关工作阅读路线

## 1. 第一层：必须精读，直接决定问题定义

### SAM3

读共享 concept grounding、presence token、object queries 和 segmentation readout。写 baseline 时必须说明 P/S/I 是共享条件计算的不同 readouts，而非三个独立网络。

文件：`A_核心必读/SAM3_2511.16719.pdf`

### SegEarth-OV3

我们的直接 baseline。重点核对 Semantic/Instance/Presence 的导出、instance aggregation、native fusion、类别别名与数据协议。

文件：`A_核心必读/SegEarth-OV3_2512.08730v2.pdf`

### ProC-SAM3

最接近的严格八数据集公开 comparator。流程是 constrained prompt pool、缓存/批量推理和 Presence-Guided Residual Fusion。它解决 prompt coverage/efficiency 和 head fusion，但仍主要从 prompt-level 组织信息；我们的区分点是 readout responsibility 与 visual observation 的联合证据组织。

文件：`A_核心必读/ProC-SAM3_2606.21863.pdf`

### ConceptBank

从目标支持数据建立 visual concept prototypes，用 SAM3 实际分割功能而非单纯 embedding similarity 评价 prompt。它支持“prompt quality 应由 segmentation function 判断”的理念，但使用 support data / GT，与我们的 zero-support setting 不同。

文件：`A_核心必读/ConceptBank_2602.06333.pdf`

### CoCo-SAM3

研究跨类别 concept conflict 与分数可比性，使用受限同义/词形扩展和校准。它帮助界定类别语义边界，但不等于 P/S/I role specialization。

文件：`A_核心必读/CoCo-SAM3_2604.19648.pdf`

### Promptable Concept Segmentation from Above

直接研究 SAM3 在俯视场景中的 concept segmentation，Presence 与 localization 能力差异可作为我们问题动机，但不能替代自己的三路实验证据。

文件：`A_核心必读/Promptable-Concept-Segmentation-from-Above_2607.09583.pdf`

## 2. 第二层：遥感 Training-Free OVSS 的方法谱系

- `SegEarth-OV_2410.01768.pdf`：CLIP-based training-free RS OVSS 的核心 baseline。
- `TMPA_CVPR2026.pdf`：测试时多提示适应；理解 stable text prior 与 image-conditioned update，但它是 CLIP-style alignment，不可机械映射到 SAM3。
- `ReAttnCLIP_CVPR2026.pdf`：重定义 CLIP attention，提高 dense inference。
- `ConInfer_CVPRF2026.pdf`：场景/tile 特征共识与迭代推断；用于 contextual evidence 相关工作。
- `RSGPNet_2606.28410v1.pdf`：SAM3 coarse text masks → box re-prompt → consistency verification；只报告部分数据集。
- `ReSeg-CLIP_2602.23869.pdf`：SAM masks 约束与 RS-CLIP composition；training-free 但三数据集结果较低。
- `DinoSplat-OV_2608.03023v1.pdf`：DINO/text-aware propagation 与 Gaussian upsampling；较新但数据集协议不完整可比。

严格八数据集、无训练、无 support 的公开比较截至 2026-09-27 仍以 ProC-SAM3 `56.1` 为最高已核验结果。

## 3. 第三层：Role–View 理论和叙事支撑

- `GLA-CLIP_CVPR2026.pdf`：跨窗口 global K/V 与局部 dense prediction，证明 training-free OVSS 中窗口外 context 值得研究。
- `OV-Stitcher_CVPRF2026.pdf`：跨窗口 attention stitching 与 LLM prompt，说明文本和 context 已有人共同考虑；我们的新意不能写成“首次结合 text+context”。
- `HRDA_ECCV2022.pdf`：高分辨率细节与低分辨率上下文的经典 trade-off。
- `SlowFast_ICCV2019.pdf`：不同信息通路按职责配置的设计类比；仅作直觉，不作生物学证明。
- `SeeCo_2604.26221.pdf`：training-free consensus / recalibration 参考；用于说明在线共识方向，与我们固定 role-view evidence 不是同一方法。

还应引用但本包未包含 PDF：**Dual Context-Conditioned Open-Vocabulary Semantic Segmentation in Remote Sensing**, IEEE Access 2026, DOI `10.1109/ACCESS.2026.3674757`。它使用 target tile、neighboring same-resolution tile 和 downsampled whole-scene features，是邻接/全局上下文最直接的遥感先例。正式引用前请从官方页面获取原文并核对实现细节。

## 4. 写作时如何组织 Related Work

### Training-Free OVSS and Remote Sensing

先从 CLIP dense inference、mask/query decoding、遥感 adaptation 三条线收束到 SegEarth-OV3/SAM3。结尾指出：现有方法多优化统一视觉—语言匹配或类别提示，较少讨论共享 concept 模型的 role-heterogeneous readouts。

### Prompt and Concept Adaptation for SAM3

对比 ProC、ConceptBank、CoCo、Promptable-from-Above。结尾指出：它们分别解决 prompt coverage、data-driven concept construction、class conflict 和俯视适配，但没有把 P/S/I 的补充信息需求与视觉观察共同建模。

### Global–Local Context

对比 HRDA、GLA-CLIP、OV-Stitcher、Dual Context。结尾指出：global/local 本身并不新；本项目研究的是 context 如何与 role-conditioned supplementary evidence 形成条件互补，同时保留完整 SAM3 grounding。

# 论文执笔者任务书

## 1. 论文要回答的核心问题

SegEarth-OV3 用一个统一 concept 条件化 SAM3，并从共享 grounding 中读取 Presence、Semantic 和 Instance。现有做法默认同一概念表达和同一视觉观察足以服务三种职责。我们的实验发现，补充描述不是越长越好，也不能无差别替换统一 concept；真正有效的是在保留官方类别锚点与原生耦合计算的前提下，按 readout responsibility 使用补充信息，并让补充信息从合适的视觉范围中完成 grounding。

论文应围绕一个问题、两个相连的设计展开：

1. **Role-Functional Text：What evidence should be supplemented?**
2. **Joint Role–View：Under which visual observation should that evidence be grounded and composed?**

不要把论文写成“LLM 生成提示 + 多尺度推理”两个松散技巧的拼接。

## 2. 建议的三条贡献

1. 揭示共享 concept grounding 下不同 SAM3 readouts 对补充语言证据的功能异质性，并提出保留 anchor 的 Role-Functional Text 组织方式。
2. 提出 Joint Role–View evidence specialization，让角色化补充在完整 Local/Global grounding 后进行对齐证据组合，利用语言条件与视觉范围之间的条件互补。
3. 在八个遥感数据集上进行系统验证，并通过 matched factorial interaction、类别/像素变化、自然域扩展和失败对照解释方法何时有效、何时收益重叠。

第三条是系统实证贡献，不需要再发明第三个算法模块。

## 3. 推荐的主文结构

### Introduction

从“统一 concept 的价值与限制”进入，而不是从“遥感域差异很大”泛泛进入：

1. SAM3 使开放词汇分割从 CLIP 像素相似度转向 concept-conditioned segmentation。
2. 统一 concept 确保类别边界和三路共识，但 P/S/I 的计算职责不同。
3. 遥感中视觉外观、覆盖范围、区域组织和场景存在性对不同 readout 的作用不同。
4. 直接替换、共享新文本或隔离内部状态都不能稳定利用补充信息。
5. 因而提出保留共享 grounding 的 Role–View Evidence Specialization。

### Related Work

建议三节：

1. Training-Free OVSS and Remote-Sensing OVSS；
2. Prompt / Concept Adaptation for SAM3；
3. Global–Local Context and Evidence Composition。

每节最后一句都要落到“已有工作解决了什么、仍未研究什么”，不要只罗列论文。

### Method

建议四节：

1. Preliminaries: SegEarth-OV3 / SAM3 shared grounding and P/S/I readouts；
2. Role-Functional Text with anchor-preserving correction；
3. Aligned Local/Global observations and Joint Role–View composition；
4. Inference protocol and selected profile definition。

### Experiments

建议六节：

1. Setup and protocols；
2. Main comparison；
3. Component ablation；
4. Matched Role×View interaction；
5. Class/pixel mechanism and qualitative results；
6. Natural-domain extension and limitations。

## 4. 主文优先展示什么

1. 一张真实方法主图：完整 SAM3 grounding、P/S/I 角色化补充、两个视图、对齐 score fusion。
2. 一张主对比表：PPT 第16页的完整方法表，不只比较 baseline 和 ProC。
3. 一张组件表：Baseline → Role → Joint。
4. 一张 matched 2×2 interaction 表：证明不是独立收益简单相加。
5. 一张类别组增益图和 2–3 组真实分割图。
6. 一个紧凑的设计对照：共享/替换/残差/隔离失败如何导向当前方法。

## 5. 不得出现的表述

- “三个 head 独立接收不同文本”：实际是每个候选都完整重跑原生 grounding，随后只使用指定角色输出。
- “P 看 Global、S 看中尺度、I 看 Local”：当前没有 per-head view routing。
- “我们修改了 Fusion Encoder / attention”：当前没有。
- “所有数据集都是 1+1>2”：matched interaction 为正的是 6/8，iSAID/UDD5 收益重叠。
- “所有角色都必须有新文本”：多个最佳 profile 保留某些 anchor。
- “硬 max 是主要瓶颈”：现有实验不支持。
- “我们的 57.49 已经是公开 SOTA”：它是内部验证结果，尚未发表；截至 2026-09-27，严格可比的已发表/公开八数据集结果仍以 ProC-SAM3 56.1 为最高已核验值。

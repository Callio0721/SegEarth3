# 项目认识与投稿判断

> 2026-09-05。面向从实验项目转入 CVPR 论文写作的首次接手判断；保留用户确定的 57.49 主结果。本文件不是新实验报告。

## 1. 我的总体判断

**项目已经具备写完整论文第一稿的实证基础；当前最重要的工作是压实贡献归因，而不是继续增加方法分支。**

你们已经不只是“生成了一些效果好的描述”。现有研究的实质是：以 SAM3 的共享概念条件计算为基础，识别并利用其不同输出角色对补充信息的不同反应，再把这一组织方式扩展到具有不同空间范围和有效分辨率的视觉观察。

我会把论文核心问题表述为：

> **How should supplementary evidence be organized for a shared concept-grounded model with heterogeneous readout responsibilities?**

中文是：**对于共享概念 grounding、但输出职责不同的模型，应当如何组织补充证据？**

这比“遥感描述不够好，所以用 LLM”“不同数据集要不同超参数”“SAM3 的 max 不合理”更贴近实际方法，也更容易形成统一论文。

但目前还不能仅凭八数据集提升就判断论文已经达到录用标准。最可能的核心审稿问题是：

> 这项工作相对于已有的多提示集成和多尺度推理，新增的有效原理究竟是什么？收益有多少来自角色分配，而不是更多文本、更多观察和候选筛选？

这不是要求发明复杂网络，而是要求现有简单结构有清楚、充分、可检验的理由。

## 2. 我如何理解当前真实方法

### 2.1 Baseline 不是三个独立模型

SegEarth-OV3 利用 SAM3 的共享概念条件计算，读取三个有不同职责的输出：

- Presence：当前概念在图像中是否成立的类别级支持。
- Semantic：该概念的稠密覆盖。
- Instance：query 对区域的组织、定位、mask 和对象置信度。

Instance 的“连通与组织”不是严格的连通性约束，更不是文本 embedding 本身；它描述的是 query 生成区域证据的功能。不能写成“Instance 天生只适合小目标”，也不能写成它只负责边界。

当前代码的实例图包含 Presence 调制。用 `r` 表示 raw object confidence：

\[
I_c(x;p,a)=\max_{q:a_c r_{cq}>\eta} M_{cq}(x)r_{cq}p_c,
\qquad F_c(x)=p_c\max(S_c(x),I_c(x;p,a)).
\]

默认 admission 的 `a=p`；保留的小型 anchor-admission 修正仅将 admission 用的 `a` 改为 `p_A`。实例幅度和最终外层 Presence 并未随之取消。

### 2.2 第一方法：完整 grounding，选择性使用补充

对官方类别词及别名保留 anchor。Presence / Semantic / Instance 的候选描述各自执行**完整、冻结、原生的 SAM3 grounding**，随后只使用指定角色的输出作有界修正。

因此真实方法不是：

> 把三个不同文本分别直接塞进三个已经拆开的 head。

而是：

> 不拆开预训练计算，区分不同补充文本产生的证据在输出组合中的用途。

特别地，Presence 更新后还会影响实例的筛选与幅度；这是保留的原生耦合，不是代码意外。

每个单元最终使用 `official + role-composed − composed-anchor` 的补偿，保留官方别名和原有聚合结果。只写 `O=O_A+ΔO` 会漏掉这一层，但它应在正文精炼公式与补充算法中交代清楚。

### 2.3 第二方法：不同观察提供证据，不修改内部 attention

Local / Global 分别完成完整 grounding，**相同的已选 P/S/I 文本配置在两个视图上使用**。先在每个视图中完成角色修正与原生融合，再恢复到同一目标坐标，融合连续类别分数图，最后作类别决策。

```text
                   Official anchor + role supplementary texts
                                      │
                ┌─────────────────────┴─────────────────────┐
                │                                           │
          Local observation                          Global observation
                │                                           │
       Full native grounding                       Full native grounding
       for each needed prompt                      for each needed prompt
                │                                           │
       Role-specific correction                    Role-specific correction
       + native P/S/I composition                  + native P/S/I composition
                │                                           │
       Restore / aggregate                         Restore target coordinates
                └─────────────────────┬─────────────────────┘
                           Aligned view evidence fusion
                                      │
                         Original class decision / threshold
```

这里的“Joint”是角色配置与视图使用的联合考虑，不是已经实现了“P 看全局、S 看中尺度、I 看局部”的三路视觉路由，也不是两个视图在 fusion encoder 中交换 token。主图、摘要和方法正文必须统一这一点。

## 3. 现有成果的分量

### 3.1 固定主方法：八个遥感基准均有提升

以下为配对日志口径；不是改写用户指定的对外比较表。

| Dataset | Baseline | Role-only | Joint | Role 增益 | Joint 相对 Role |
|---|---:|---:|---:|---:|---:|
| Potsdam | 57.87 | 58.59 | 63.18 | +0.73 | +4.59 |
| Vaihingen | 60.86 | 62.33 | 66.38 | +1.47 | +4.05 |
| LoveDA | 47.34 | 48.30 | 48.81 | +0.96 | +0.50 |
| iSAID | 27.64 | 28.27 | 29.13 | +0.63 | +0.86 |
| OEM | 44.30 | 50.53 | 53.08 | +6.23 | +2.55 |
| UAVid | 54.58 | 59.51 | 59.82 | +4.92 | +0.31 |
| UDD5 | 71.80 | 72.89 | 72.94 | +1.08 | +0.06 |
| VDD | 64.11 | 66.12 | 66.55 | +2.01 | +0.44 |
| **Macro** | **53.56** | **55.82** | **57.49** | **+2.25** | **+1.67** |

均由完整精度计算后舍入。Role-only 是其阶段已选结果；不一定与最终 Joint 使用同一角色配置。因此这张表说明研究进展和最终表现，不能直接用来计算严格 interaction。

### 3.2 最有方法意义的不是单个最高分，而是条件互补

固定最终 Joint 的角色与融合设置作四格比较后：

- Baseline：53.56。
- 同一 Role 配置单独使用：55.67。
- 同一 View 配置、只用 anchor：54.75。
- 同一配置同时使用：57.49。
- 平均 performance interaction：**+0.63**，**6/8** 为正。

LoveDA / UAVid 尤其有说服力：对应 View 配置在 anchor 下分别为 −0.16 / −0.15，加入 Role 后相对 Role-only 却能增加 +0.50 / +0.32。这说明视觉补充的可用性依赖文本条件，不只是两个独立正收益相加。

OEM / Vaihingen 的 interaction 达 +1.68 / +2.07，是强案例。Potsdam 的主要收益是 View 主效应，interaction 只有 +0.11；iSAID / UDD5 的 interaction 为负，表明收益存在重叠。**“条件互补”比“所有场景 1+1>2”更准确，也更有解释力。**

### 3.3 提升不是只有背景或漂亮数字

现有类别统计中，Joint 提高 48/63 个遥感 dataset–class pairs。日志记录约 4.29 亿评测像素由错变对，约 1.66 亿由对变错，净纠正约 2.63 亿。这些是评测网格计数，不应解释成互不重叠的独立地理像素样本。

水域、植被/地表覆盖、建筑结构整体更受益；移动目标亦有平均增益，但并非所有道路或小目标都增加。背景/杂项平均增益很大且被 OEM background 显著影响。因此最好的呈现是带类别数量的分组柱图与真实分割对比，而不是仅用一个相关系数声称“越弱的类别必然提升越多”。

自然域补充也有价值：Cityscapes 67.90→72.20，VOC20 96.89→97.11。但 Cityscapes 的最终 View 退化为 Global，不能把它作为第二方法也有效的证据；这属于经过相应配置评估的跨域适用性，不是保持遥感配置原样迁移。

## 4. 本轮发现：哪些旧表述需要修正

### 4.1 共享补充文本不是天然无效

旧试错页中的 `0/36` 描述的是早期文本与特定替换路径。后期 `role_text_completion_v1_full_99f03ff` 还保留了完整 grounding、同一文本同时修正三角色的有界残差控制。

| Dataset | 同一 S3 只修正 Semantic | 同一 S3 修正全部角色 | 本实验 baseline |
|---|---:|---:|---:|
| OEM | **46.28** | 44.02 | 44.30 |
| UDD5 | 71.56 | **73.04** | 71.80 |
| Vaihingen | **61.57** | 61.28 | 60.86 |

全部 S1–S3 共 18 个共享配置，有 **7/18** 超过 baseline。UDD5 的共享 S3 甚至超过当前已选 Role-only / Joint 的 72.89 / 72.94。

它不要求现在改动用户冻结的主表，也不能拿这三行不同选择预算对照直接当作完整方法排名。但它确实要求论文取消“三头必须不同”“统一文本都会破坏”的绝对表述。

更强、也与这些结果一致的发现是：**同一条补充文本，作用范围不同会显著改变收益；其角色适配性不由人类为它标注的用途自动决定。** OEM 与 UDD5 的反向结果正适合用于解释“有选择的分配”，不应隐藏后一种结果。

### 4.2 Direct 对照支持完整 anchor-preserving 策略，不单独证明 clipping

当前最终 Direct 分支直接使用新组合，而 Residual 分支还保留 `official + composed − anchor` 的官方输出补偿。两者不仅差一个残差幅度或 clipping。

因此六数据集 Direct / Residual 的明显差距可以支持：**当前完整的 anchor-preserving 组合策略是更可靠的默认。**

不能把全部差距写成“裁剪这一行代码独立带来这些提升”。若希望证明这一更细的结论，才需要固定官方别名补偿的纯更新形式对照；否则收紧表述就足够，不必为论文不断加实验。

### 4.3 我不会把现有模型描述成新的内部架构

现在没有训练新的 role-specific decoder，没有 latent role-view attention，没有 PE 文本空间新对齐。这些都曾经是探索方向，但不是最终方法。

可以强调的是**对冻结模型证据的功能组织**，不能用更复杂的架构图掩盖实际是输出级角色修正与视图融合。简单方法可以形成论文，前提是实验明确证明设计原则的价值。

## 5. 失败实验应该如何服务论文

不把所有失败方法铺成一章。我会归并为三个与最终设计直接相连的问题：

| 试错揭示的限制 | 有代表性的实验 | 对最终设计的作用 |
|---|---|---|
| 新描述不等于可直接替代原语义 | 早期统一重提示、直接替换及后期共享文本控制 | 保留官方 anchor，允许有选择的角色修正 |
| 可预测信号不等于可操作的纠错信息 | Block23 边界相关性与实际修边失败；自提示错误强化 | 不把内部自信度/几何相关性当成第二方法的充分依据 |
| 功能差异不等于可以拆开预训练计算 | anchor-clamped replay 下降 | 保留完整 grounding，在证据使用层面区分角色 |

主文只放第一组紧邻核心设计的紧凑对照；第二、三组各用一句有出处的观察解释设计取舍，完整数据进补充。不存在“做了更多失败实验，所以创新性更强”的逻辑。

## 6. 对 CVPR 投稿的定位

### 可以成为优势的部分

1. 问题依赖 SAM3 的真实架构角色，不是把 CLIP prompt tuning 机械搬来。
2. 八个遥感基准和两个自然域扩展形成较宽实证面。
3. 有单独模块、联合配置、同配置四格 interaction、类别/像素变化和多条反例，可组织成完整证据链。
4. 不需要增加训练模块；提出并验证清晰的证据使用方式本身可以有研究价值。

### 目前仍需压实的部分

1. **核心优先项：角色分配的归因。** 当前已经有同文本不同用途的对照，但最终文本池下与普通多提示输出集成的配对控制仍最有价值。不能把“多了三类文本”本身当成角色分配的证明。
2. **第二方法的独特性。** 多尺度/全局局部本身不是新概念。新增价值应落在对 role-conditioned evidence 的条件互补以及联合配置必要性，而非宣称发明 Local/Global。
3. **文字与实现一致。** 角色不是隔离计算，Joint 不是内部 attention，anchor-admission 不是少乘 Presence。
4. **主实验可审阅。** 主表数值来源、上下文范围和配置清单要明确；真实定性图必须来自已选方法输出，不能误用筛查程序默认返回的 baseline 图。

我的判断不是“必须再做一个第三创新点”，而是：**先把这两个连接紧密的设计写成一篇完整、证据充分的论文。** 如果最关键的配对控制不能支持角色组织的额外价值，再调整贡献表述，而不是继续叠模块维持叙事。

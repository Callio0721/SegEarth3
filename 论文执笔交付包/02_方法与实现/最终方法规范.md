# 最终方法规范：Role–View Evidence Specialization

## 1. Baseline 计算对象

对图像 `X` 和类别 concept `t_c`，SAM3 首先形成共享条件状态：

\[
H_c=\Phi(X,t_c).
\]

三路输出是同一次共享 grounding 的不同 readouts：

- Presence `p_c`：类别级存在证据；
- Semantic `S_c(x)`：稠密类别覆盖；
- Instance：object queries 产生 mask `M_cq(x)` 与 raw confidence `r_cq`。

当前实现中的实例与最终证据为：

\[
Q_c=\{q:p_cr_{cq}>\eta\},
\]

\[
I_c(x)=\max_{q\in Q_c}M_{cq}(x)r_{cq}p_c,
\]

\[
F_c(x)=p_c\max(S_c(x),I_c(x)).
\]

Presence 因而参与 query admission、instance amplitude 和最终 class scaling。论文不能把它简化为只在末端乘一次。

## 2. Part I：Role-Functional Text

### 2.1 Anchor

每个类别首先保留 baseline 的 official class name / aliases，得到 anchor 输出：

\[
(p_c^A,S_c^A,I_c^A).
\]

Anchor 保留类别边界、官方 ontology 以及三路共享的基本共识。

### 2.2 Role-functional candidates

候选补充文本按功能设计：

- Presence：概念在当前场景中如何被建立或可见；
- Semantic：dense appearance、surface、coverage 与 continuity；
- Instance：query 对实体或连通区域的组织、分离与定位。

这里的 Instance “region organization”不是显式拓扑 loss，也不是文本 embedding 自己形成实例；它描述补充信息希望影响 object-query region evidence 的功能。

### 2.3 完整 grounding，选择性使用

每条候选文本都执行完整、冻结、原生 SAM3 grounding：

\[
(X,t_c^r)\rightarrow(p_c^r,S_c^r,I_c^r).
\]

随后只使用其被分配 role 的输出形成有界 correction，而不是把文本硬接到一个隔离的 head：

\[
O_c^{\prime r}=O_c^{A}+\alpha_r\operatorname{clip}
(O_c^r-O_c^A,-\tau_r,\tau_r),\quad r\in\{P,S,I\}.
\]

实现默认 `alpha=0.5, tau=0.25`。Presence 更新后会重新参与实例重建，因此 P/I 仍保持原生耦合。`anchor_admission` 仅在被选 profile 中令硬 query admission 使用 anchor Presence；它不取消 instance amplitude 或最终 scaling 中的 Presence。

对包含 aliases 的实际 unit，代码还使用：

\[
G_v=\operatorname{clip}(B_v^{official}+F_v^{\theta}-F_v^0,0,1),
\]

确保 official aliases 和空间聚合不被丢失。正文可给紧凑式，补充材料需给完整算法。

## 3. Part II：Joint Role–View Profile

### 3.1 两种观察

- Local / Native：较高有效分辨率，保留局部细节、小实体和边界；
- Global / Context：较大空间范围，提供布局、连续性和低频结构。

两个视图都对所需 prompts 完成完整 frozen grounding；它们不是从同一个输出上做后处理。

### 3.2 每个视图内先完成 Role composition

相同的已选 P/S/I slots 被应用在 Local 与 Global 两个视图上。每个视图内部先完成：

1. official anchor；
2. role-specific bounded correction；
3. 原生 `p × max(S,I)`；
4. official aliases / spatial units 聚合。

当前方法没有 `P→Global, S→Global, I→Local` 这种显式 per-head view routing。

### 3.3 坐标恢复与 View evidence composition

Local 与 Global 输出都恢复到目标区域同一 `C×H×W` 坐标，得到 `G_L` 和 `G_G`，再由 profile 指定的轻量 frozen operator 组合：

\[
Z=\Psi(G_L,G_G).
\]

最后保持 baseline 的跨类别 `argmax` 与 background threshold。算子可以是 max、linear、logit 或 power family；具体算子属于 dataset profile，不是框架创新本身，也不应在方法标题中突出。

## 4. 统一逻辑

```text
Official concept anchor
        │
Role-functional supplementary texts
        │  full native grounding for each needed prompt
        ▼
Role-aware bounded evidence correction
        │
        ├──────── Local observation ────────┐
        │                                   │
        └──────── Global observation ───────┤
                                            ▼
                       aligned view evidence composition
                                            │
                             original class decision
```

核心不是“更多 prompt + 更多尺度”，而是：

\[
\text{shared category anchor}
+\text{role-dependent supplementary evidence}
+\text{observation-dependent evidence availability}.
\]

## 6. 与相近方法的结构差异

- ProC-SAM3：约束 prompt pool + batched inference + PGRF，重点是 prompt 扩展与 P/S/I 输出融合；我们的核心是不同 readout responsibility 的补充证据组织，再与视觉观察联合。
- ConceptBank：以 support-data visual prototypes 产生/筛选 concept embeddings，并用真实分割功能评价；我们不使用 support GT 或 prototype bank。
- CoCo-SAM3：处理类别间 concept conflict 和可比性；我们不重标定类别词义边界，重点是同一类别内部 P/S/I 的功能需求。
- GLA-CLIP / OV-Stitcher：在 CLIP attention/window 层引入全局上下文；我们保持 SAM3 内部 attention 不变，在完整 grounding 之后对齐 view evidence。

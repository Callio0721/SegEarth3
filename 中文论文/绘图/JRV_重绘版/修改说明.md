## 原图的具体问题与改法
1. 外围大虚线框、内部小边框和标题框同时竞争注意力。新版删除无计算含义的嵌套边框，只保留轻底色模块和明确的章节层级。
2. P/S/I 的示意图分别使用图网络、卡通道路和曲线，视觉语言不一致；Presence 的图网络还容易被误读为新增图网络模块。新版将三者统一成文本证据卡片，固定紫、青、橙三色。
3. 原图 SAM3 纵向过窄、文字断行，新增部分没有清楚的中间输出。新版使用等宽平行 Local/Context 流程和共享权重说明，显式显示完整 P/S/I 输出、角色更新、官方图补偿与坐标恢复。
4. 原图 Native Role Composition 近似漂浮标签，缺少操作对象。新版在主图保留核心 p×max(S,I)，细节页展开 p̃→Instance 重建，避免让人误以为三个 head 独立运行。
5. “Role-Aligned View Integration”容易暗示逐 head 的视图路由。新版明确为完整类别分数场的融合，放在类别决策之前；两个视图使用同一 profile。
6. 正文主图只承载数据流，公式与耦合放到第二页。若只放一张图，优先第一页，第二页用于方法细节或补充材料。

## 真实性与术语
- 图中的道路照片复用原始 PPT。没有生成新的预测 mask。
- 文本短语保留原图举例，不表示每个数据集均选择这些确切候选。
- 分数场叠片是示意，不是实际热图。原有彩色 mask 的实验身份未核验，未用作新图的效果证据。
- profile 是数据集级离线配置，不是可训练模块或逐图自动选择器。论文当前写明评测标注参与配置选择，应在正文协议中继续明确。
- 第二页 Q 表示用于重建的 query mask/confidence 信息；instance admission 与 amplitude 仍受 Presence 影响。
- 未改写论文的结果或 SOTA 结论。修改之后的论文.md 中较强的 SOTA/“完美贴合”等措辞与完整中文稿的证据边界并不一致；图中不放这些未经统一的宣称。

## 使用建议
- 总览与细节分别作为 Figure 2 / Figure 3，或合为主图与补充图。
- PPT 使用 DejaVu Sans。若本机没有该字体，请统一替换为 Arial 或 Aptos 后检查长文本；PDF 可作版式参考。
- 论文排版时可删除大标题和副标题，由 figure caption 承担；主图建议跨双栏放置。保留子图编号、三个角色颜色和两条相同流程。
- PowerPoint 中文字、模块、表格单元和连线均可编辑；原始照片为位图。PDF 是同源绘制而非 Office 导出，最终投稿前应在实际 Office 中检查字体替换后的排版并导出。

## 建议图注
Overview of Joint Role–View Specialization (JRV). Official class names and aliases define the anchor, while role-functional text supplements provide candidate evidence. Each required prompt is fully grounded by the frozen SAM3 model under Local and Context observations using the same role profile. Bounded role updates preserve the native Presence–Instance coupling. Official-map correction and coordinate restoration produce aligned class-score fields, which are combined by a fixed profile operator before the original class decision. Images and score-field stacks illustrate the computation rather than quantitative predictions.

原始 PPT、论文、实验代码与 state.md 均未修改。所有交付文件仅供本地论文绘图使用，无需复制到远程训练服务器。
